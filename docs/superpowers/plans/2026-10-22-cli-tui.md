# Desktop CLI redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every desktop `flocc` command shows its work live through one event session, drawn
full-screen, inline or plain, and hosts join the tailnet tagged without a QR login.

**Architecture:** A new `ui.Session` turns calls (groups, steps, prompts, handoffs, tables) into
events on one channel; a renderer goroutine draws them. Plain is a line writer; inline and
full-screen are Bubble Tea v2 programs. `host.Exec.Interactive` hands the terminal to children
through the session. The host's `flocc-setup` sends the same events as JSON lines, which `ship`
replays. A `tailnet` package talks to the Tailscale API with an owner-made OAuth client.

**Tech Stack:** Go 1.26 (`mise.toml`), `charm.land/bubbletea/v2` v2.0.2, `charm.land/bubbles/v2`
v2.0.0, `charm.land/lipgloss/v2` v2.0.6, `charm.land/huh/v2` v2.0.3 (all already in `go.mod`),
Python 3 host CLI under `src/flocc`.

**Spec:** `docs/superpowers/specs/2026-10-22-cli-tui-design.md` (parts 1–3) and
`docs/superpowers/specs/2026-10-22-tailnet-hands-off-design.md` (part 4). Read both before a task.

## Global Constraints

- Stay on the pinned Charm versions above. No upgrade in this plan.
- No new Go module dependency except where a task names one.
- Plain output never writes an escape code or a carriage return. Glyphs stay: ✓ ✗ • · →.
- Nothing on the desktop writes to the terminal outside the session once Task 7 lands.
- Errors and lines from the far end pass through `saved.SanitizeBlock` / `saved.Sanitize` before they are drawn, as today.
- Secrets never reach a log or an event: register them with the existing redacting logs first.
- Every commit: `git commit -s`, no `Co-Authored-By`, no AI attribution.
- Run `just check` (lint + Python and Go tests) before each commit; it must pass.
- Match the surrounding code's comment density: comments carry facts the code cannot show.
- Renderer choice: `--plain`, `--inline`, `--full` flags (stripped in `cli.run` before dispatch), else `FLOCC_UI` = `plain|inline|full`, else the command's default. A non-terminal stdout, `NO_COLOR` or `TERM=dumb` always gives plain.
- Until Part 3 lands, `full` falls back to `inline`.
- Do not ship to or restart services on the live host `flocc-nimble` or touch `cardinal` on `zer0-day-nimble` while executing this plan; live checks are listed in Task 33 for the owner.

## Review Focus

1. **A step ended twice or never.** A step whose goroutine both `Fail`s and `Done`s, or returns without ending, must leave exactly one row; `Close` ends any open step as failed "did not finish". Test in Task 2.
2. **Output from a goroutine while a prompt is open.** A parallel step finishing during a prompt must not corrupt the form; the row queues and prints after. Test in Task 4.
3. **Ctrl-C during a prompt vs during a handoff.** In a prompt it stops the run (today's `w.stopped`); during a handoff it reaches the child only. The prompt half is tested in Tasks 4 and 8; the handoff half needs a real terminal and is item 4 of Task 33.
4. **A host stream cut mid-step or full of non-event lines** (apt output, a sudo lecture, a partial JSON line): no panic, stray lines become step lines, a cut-off fails the step with the last 20. Test in Task 15.
5. **A narrow or resized terminal.** Inline cuts lines to width; full-screen below 80×20 hands over to inline mid-run without losing rows. Tests in Tasks 4 and 22.

```go
package ui

// Kind is what an event draws.
type Kind string

const (
	KGroup Kind = "group" // a section heading; later steps belong to it
	KStep  Kind = "step"  // a row; State says whether it still runs
	KLine  Kind = "line"  // a command or output line of the step ID, for the tail and the log
	KNote  Kind = "note"
	KTodo  Kind = "todo" // collected into the "still yours to do" box
	KTable Kind = "table"
	KPlan  Kind = "plan" // the groups to come, one per line of Text, for the full-screen rail
	KLog   Kind = "log"  // Text is the log file the record names at the end
	KData  Kind = "data" // machine data for the desktop under Name (a host summary); never drawn
)

type State string

const (
	Running State = "running"
	Done    State = "done"
	Pending State = "pending" // did what it could; the owner has the rest
	Skipped State = "skipped"
	Failed  State = "failed"
)

// Event is one thing the session draws. A step sends one event per change under the same ID;
// the last one has a State other than Running. The wire format in wire.go is this struct as JSON.
type Event struct {
	Kind   Kind   `json:"type"`
	ID     string `json:"id,omitempty"`
	Name   string `json:"name,omitempty"`
	Detail string `json:"detail,omitempty"`
	Text   string `json:"text,omitempty"` // a line's text, a note's body, a to-do
	State  State  `json:"state,omitempty"`
	N      int    `json:"n,omitempty"` // progress: N of Total
	Total  int    `json:"total,omitempty"`
	Err    string `json:"err,omitempty"`
	Table  *Table `json:"table,omitempty"`
}

// Table is a titled grid; renderers pick their own borders.
type Table struct {
	Title   string     `json:"title,omitempty"`
	Headers []string   `json:"headers"`
	Rows    [][]string `json:"rows"`
}
```

`rows.go`:

```go
package ui

import (
	"fmt"
	"strings"
)

var marks = map[State]struct{ glyph, code string }{
	Running: {"→", ""}, Done: {"✓", "32"}, Pending: {"•", "33"}, Skipped: {"·", ""}, Failed: {"✗", "31"},
}

// Mark is a state's glyph, in the terminal's own 16 colours when color is set.
func Mark(s State, color bool) string {
	m := marks[s]
	return Out{Color: color}.paint(m.code, m.glyph)
}

// RowText is an ended step as the plain and inline renderers print it: two spaces in, the mark,
// the name padded to nameWidth, the detail (or the error), continuation lines under the detail.
func RowText(e Event, nameWidth int, color bool) string {
	detail := e.Detail
	if e.State == Failed && e.Err != "" {
		detail = e.Err
	}
	lines := strings.Split(strings.TrimRight(detail, "\n"), "\n")
	head := fmt.Sprintf("%s%s %-*s %s", indent, Mark(e.State, color), nameWidth, e.Name, lines[0])
	out := []string{strings.TrimRight(head, " ")}
	pad := strings.Repeat(" ", len(indent)+2+nameWidth+1)
	for _, l := range lines[1:] {
		out = append(out, pad+l)
	}
	return strings.Join(out, "\n")
}
```

```go
package ui

import (
	"cmp"
	"errors"
	"fmt"
	"os/exec"
	"strings"
	"sync"

	"charm.land/huh/v2"
)

// session serialises every call into Renderer.Draw under one mutex, so a renderer sees events in
// one order and never from two goroutines at once. Prompts and handoffs hold no lock while they
// block: a parallel step may end meanwhile, and the renderer queues its row (Review Focus 2).
type session struct {
	r      Renderer
	mu     sync.Mutex
	next   int
	open   map[string]*Step
	todos  []string
	failed bool
	closed bool
}

func New(r Renderer) Session { return &session{r: r, open: map[string]*Step{}} }

type Step struct {
	s    *session
	id   string
	name string
	ended bool
}

func (s *session) draw(e Event) {
	s.mu.Lock()
	defer s.mu.Unlock()
	if !s.closed {
		s.r.Draw(e)
	}
}

func (s *session) Group(title string) { s.draw(Event{Kind: KGroup, Name: title}) }

func (s *session) Step(name string) *Step {
	s.mu.Lock()
	s.next++
	st := &Step{s: s, id: fmt.Sprintf("s%d", s.next), name: name}
	s.open[st.id] = st
	s.mu.Unlock()
	s.draw(Event{Kind: KStep, ID: st.id, Name: name, State: Running})
	return st
}

func (s *session) Note(title, body string) { s.draw(Event{Kind: KNote, Name: title, Text: body}) }

func (s *session) Todo(text string) {
	s.mu.Lock()
	s.todos = append(s.todos, text)
	s.mu.Unlock()
	s.draw(Event{Kind: KTodo, Text: text})
}

func (s *session) Table(t Table) { s.draw(Event{Kind: KTable, Table: &t}) }

func (s *session) Plan(groups []string) { s.draw(Event{Kind: KPlan, Text: strings.Join(groups, "\n")}) }
func (s *session) LogPath(p string)     { s.draw(Event{Kind: KLog, Text: p}) }

// Rows draws rows that were decided elsewhere (a host summary, a cardinal report) as steps.
func Rows(s Session, evs []Event) {
	for _, e := range evs {
		st := s.Step(e.Name)
		switch e.State {
		case Done:
			st.Done(e.Detail)
		case Pending:
			st.Pending(e.Detail)
		case Skipped:
			st.Skip(e.Detail)
		default:
			st.Fail(errors.New(cmp.Or(e.Err, e.Detail)))
		}
	}
}

func (s *session) prompt(p PromptReq) (any, error) { return s.r.Prompt(p) }

func (s *session) Confirm(q Question) (bool, error) {
	v, err := s.prompt(PromptReq{Kind: PConfirm, Q: q})
	b, _ := v.(bool)
	return b, err
}

func (s *session) Ask(q Question) (string, error) {
	v, err := s.prompt(PromptReq{Kind: PAsk, Q: q})
	str, _ := v.(string)
	return str, err
}

func (s *session) Secret(q Question) (string, error) {
	v, err := s.prompt(PromptReq{Kind: PSecret, Q: q})
	str, _ := v.(string)
	return str, err
}

func (s *session) Choose(q Question, options []string) (int, error) {
	v, err := s.prompt(PromptReq{Kind: PChoose, Q: q, Options: options})
	i, _ := v.(int)
	return i, err
}

func (s *session) Form(f *huh.Form) error {
	_, err := s.prompt(PromptReq{Kind: PForm, Form: f})
	return err
}

func (s *session) Handoff(why string, c *exec.Cmd) error { return s.r.Handoff(why, c) }

func (s *session) Failed() bool {
	s.mu.Lock()
	defer s.mu.Unlock()
	return s.failed
}

func (s *session) Close() int {
	s.mu.Lock()
	open := make([]*Step, 0, len(s.open))
	for _, st := range s.open {
		open = append(open, st)
	}
	s.mu.Unlock()
	for _, st := range open {
		st.end(Event{State: Failed, Err: "did not finish"})
	}
	s.mu.Lock()
	defer s.mu.Unlock()
	s.closed = true
	code := s.r.Close(s.todos)
	if s.failed {
		code = 1
	}
	return code
}

func (st *Step) send(e Event) {
	e.Kind, e.ID, e.Name = KStep, st.id, st.name
	st.s.draw(e)
}

func (st *Step) Detail(text string)    { st.send(Event{State: Running, Detail: text}) }
func (st *Step) Progress(n, total int) { st.send(Event{State: Running, N: n, Total: total}) }
func (st *Step) Line(text string)      { st.s.draw(Event{Kind: KLine, ID: st.id, Text: text}) }
func (st *Step) Done(detail string)    { st.end(Event{State: Done, Detail: detail}) }
func (st *Step) Pending(detail string) { st.end(Event{State: Pending, Detail: detail}) }
func (st *Step) Skip(detail string)    { st.end(Event{State: Skipped, Detail: detail}) }
func (st *Step) Fail(err error)        { st.end(Event{State: Failed, Err: err.Error()}) }

// end sends the step's last event; any later call is dropped (Review Focus 1).
func (st *Step) end(e Event) {
	st.s.mu.Lock()
	if st.ended {
		st.s.mu.Unlock()
		return
	}
	st.ended = true
	delete(st.s.open, st.id)
	if e.State == Failed || e.State == Pending {
		st.s.failed = true
	}
	st.s.mu.Unlock()
	st.send(e)
}
```

Put `Question`, `PromptKind` (`PConfirm`, `PAsk`, `PSecret`, `PChoose`, `PForm`), `PromptReq`,
`Renderer` and `Session` in `session.go` above this, exactly as in Interfaces. Note `Close` holds
the lock while calling `r.Close`; `draw` checks `closed`, so a late event after `Close` is dropped.
Do not call `s.draw` while holding `s.mu` (deadlock): `end` releases before `send`.

`record.go`:

```go
package ui

import (
	"errors"
	"os/exec"
)

// Recorder keeps what a session sends, for tests. Answers are returned to prompts in order; a
// prompt past the end gets ErrNoAnswer.
type Recorder struct {
	Events   []Event
	Answers  []any
	Asked    []PromptReq
	Handoffs []string
	Todos    []string
	Closed   bool
}

var ErrNoAnswer = errors.New("recorder: no answer left")

func (r *Recorder) Draw(e Event) { r.Events = append(r.Events, e) }

func (r *Recorder) Prompt(p PromptReq) (any, error) {
	r.Asked = append(r.Asked, p)
	if len(r.Answers) == 0 {
		return nil, ErrNoAnswer
	}
	v := r.Answers[0]
	r.Answers = r.Answers[1:]
	if err, ok := v.(error); ok {
		return nil, err
	}
	return v, nil
}

func (r *Recorder) Handoff(why string, c *exec.Cmd) error {
	r.Handoffs = append(r.Handoffs, why)
	return nil
}

func (r *Recorder) Close(todos []string) int { r.Todos, r.Closed = todos, true; return 0 }

// Rows is every step's last event, in the order the steps ended.
func (r *Recorder) Rows() []Event {
	var out []Event
	for _, e := range r.Events {
		if e.Kind == KStep && e.State != Running {
			out = append(out, e)
		}
	}
	return out
}
```

`Prompt` on the Recorder is called without the session lock, and `Draw` with it; tests that answer
prompts from several goroutines are not needed, so the Recorder takes no lock of its own.

### Task 3: The plain renderer

**Files:**
- Create: `installer/internal/ui/plain.go`
- Test: `installer/internal/ui/plain_test.go`

**Interfaces:**
- Consumes: Tasks 1–2.
- Produces: `func NewPlain(out io.Writer, in io.Reader, color bool) Renderer`. `color` is false for
  the plain mode proper; the inline renderer reuses `plain` with `color` true for its Println text.

Behaviour:
- `KGroup`: blank line before it unless it is the first output, then the title at column 0.
- `KStep` running: nothing (plain draws no live state) except a step that runs over 5s gets one
  `  → name  detail` line at the first `Detail` after 5s, so a slow step is visible in a log. Use an
  injectable `now func() time.Time`.
- `KStep` ended: `RowText(e, 14, color)`.
- `KLine`: nothing (lines go to the log file the commands already keep).
- `KNote`: blank line, title, body lines indented two.
- `KTodo`: nothing until `Close`.
- `KTable`: header row and rows, columns padded to the widest cell, two spaces apart, indented two.
- Prompts: a blank line, the title, each fact indented two, the help indented two; then the
  input prompt; read a line from `in`; then write `\n` to `out`, since the typed newline is not
  echoed into a log or pipe.
  Confirm: `title [Y/n]: ` / `[y/N]: `; empty takes the default; `y`, `yes`, `n`, `no`.
  Choose: numbered options, `Choose [1-N]: `, re-ask on a bad number up to 3 times, then error.
  Secret: when `in` is `os.Stdin` and a terminal, `term.ReadPassword`; otherwise read the line.
  PForm: `f.WithAccessible(true).WithInput(in).WithOutput(out).Run()`.
  EOF on `in` returns `ErrNoTerminal` (`var ErrNoTerminal = errors.New("flocc asks here; run it in a terminal")`), which callers treat like today's `errNoTerminal`.

### Task 4: The inline renderer

**Files:**
- Create: `installer/internal/ui/inline.go`
- Test: `installer/internal/ui/inline_test.go`

**Interfaces:**
- Consumes: Tasks 1–3 (`RowText`, `Mark`).
- Produces: `func NewInline(out io.Writer, in io.Reader) Renderer`, and for tests the model
  `func newInlineModel(now func() time.Time) inlineModel` with `Update(tea.Msg) (tea.Model, tea.Cmd)`
  and `View() tea.View`, and the messages `drawMsg`, `promptMsg`, `promptReply`, `handoffMsg`.

Design:
- `NewInline` starts `tea.NewProgram(model, tea.WithOutput(out), tea.WithInput(in), tea.WithoutSignalHandler())` in a goroutine
  (without the option, the SIGINT the model sends itself on ctrl+c would make Bubble Tea quit the
  program mid-run; `cli.Main`'s `signal.NotifyContext` is what must see it)
  and returns a renderer whose methods `p.Send` messages: `drawMsg{Event}`, `promptMsg{req, reply chan}`,
  `handoffMsg{why, cmd, reply chan}`, `closeMsg{todos, reply chan}`.
- Model state: `steps []liveStep` (running, in start order; `{id, name, detail, n, total, start, lines []string (last 3)}`),
  `group string`, `queue []string` (ended rows waiting while a prompt is open), `form *huh.Form`,
  `reply chan`, `spinner spinner.Model` (bubbles v2, `spinner.MiniDot`), `width int`, `now func() time.Time`.
- `drawMsg` running: add or update the live step. Ended: remove it; text = `RowText(e, 14, true)`;
  if a form is open, append to `queue`, else return `tea.Println(text)`. `KGroup`: `tea.Println("\n" + bold(title))`.
  `KNote` and `KTable`: `tea.Println` of the plain text (reuse plain's formatting functions: move
  them into `rows.go` as `NoteText(title, body string) string` and `TableText(t Table) string` in Task 3 or here).
  `KLine`: append to the step's `lines`, keep 3.
- `promptMsg`: build a `huh.Form` from the request (`huh.NewConfirm`, `NewInput`,
  `NewInput().EchoMode(huh.EchoModeNone)`, `NewSelect[int]`, or the given form), themed with
  `Theme()`; title plus facts as the description; set `m.form`, return `m.form.Init()`. Forward
  every later message to `m.form.Update`; when `m.form.State == huh.StateCompleted`, send the value on
  `reply`, clear the form, and `tea.Println` the queued rows as one `tea.Sequence`. On
  `huh.StateAborted` reply with `huh.ErrUserAborted`.
- `handoffMsg`: `tea.Sequence(tea.Println("── "+why+" ──"), tea.ExecProcess(cmd, func(err error) tea.Msg { return handoffDone{err, reply} }))`.
  `handoffDone` sends `err` on `reply`.
- `tea.KeyPressMsg` "ctrl+c" with no form open: reply nothing; set `m.interrupted` and send
  `os.Interrupt` to the process (`syscall.Kill(os.Getpid(), syscall.SIGINT)`) so `signal.NotifyContext`
  in `cli.Main` cancels as today (Review Focus 3). With a form open huh handles it (abort).
- `closeMsg`: `tea.Sequence` of the to-do box text and `tea.Quit`; `Close` waits for `p.Wait()`.
- `View()`: one line per live step: spinner frame (yellow), name padded 14, detail cut to fit
  `width-2` with `…`, elapsed `m:ss`; under it the step's lines dimmed and indented 6; then the form's
  view when open. Lines are cut to width (Review Focus 5). Return `tea.NewView(s)`.
- `tea.WindowSizeMsg` sets `width`.
